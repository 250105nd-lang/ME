02

GRADUATION PROJECT · IN PROGRESS

Pet Digital ID

〜行政・医療・民間を繋ぐ 「命のデジタルインフラ」〜

開発中

Problem

飼い主：万が一の迷子や災害時、ペットの身元確認や既住歴の把握がスムーズに行えない
動物病院：初診時のカルテ作成や過去のアレルギー・病歴の確認に時間と手間がかかる

Solution

スキャン１秒で識別：マイクロチップやQRを活用し、個体識別と正確な医療履歴（アレルギー・ワクチンなど）を一元管理
双方にメリット：飼い主の「安心」と、動物病院の「初診問診の手間をゼロにするDX（業務効率化）」を同時に再現

System Concept

ペットショップ 初期情報登録
→
🐾 Pet Digital ID 情報管理
→
👤 飼い主 リアルタイム更新
→
🏥 動物病院 医療情報確認

Key Features

01 QRコードによる識別
02 GPSによる発見位置通知
03 医療情報の権限管理
04 画像特徴量による識別

Technology

PHP MySQL HTML/CSS JavaScript XAMPP dHash

Technical & Security Considerations

  • UUID v4を使用した 推測されにくいURL設計
  • アップロード画像から EXIF情報を削除し、 プライバシーを保護
  • 通常時は情報を非公開にし、 必要な場合のみ医療情報を 閲覧できる権限設計
WHAT I LEARNED

この制作を通して、 システム開発では機能を実装するだけでなく、 個人情報の保護やユーザーごとの アクセス権限について考えることが 重要だと学びました。
